# Hours-in-a-day widget designs

Open [index.html](index.html) for day-panel and narrow-panel previews. [block.html](block.html) shows the contiguous group including Sleep. Five individual HTML files demonstrate Phone, Gym, Reading, Movie, and Steam.

All rows are 26px high. The five proposed activities show only their icon and editable duration, with the right side left empty. Extra information and drawers are deferred. Edits exist only in the preview. No integrations or persisted application widget types are added by these prototypes.

Steam logo: [Simple Icons Steam SVG](https://github.com/simple-icons/simple-icons/blob/develop/icons/steam.svg), sourced from Valve's Steam mark. The other icons are inline SVG drawings made for this preview.
